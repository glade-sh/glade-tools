# Migrated Archive

This directory is a historical archive of older plans, packets, and working
notes that were moved out of the active support docs.

Do not use commands, private corpus names, package names, or paths in this
directory as current user guidance. Many examples predate the split between the
product `glade` CLI and first-party tools in `glade-tools`.

Use active docs and command help for current workflows:

```bash
glade --help
glade plugins --help
go run ./cmd/glade-tools --help
```

When reviving an archived plan, copy the needed facts into a new active plan
and rewrite command examples against the current product and plugin boundary.
